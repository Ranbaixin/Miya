## 一、项目概述

### 1.1 项目目标

APV2.1 是 AP (Artificial PsyArch) 认知架构原型的第二代重构版本，目标是：

1. **理论对齐**：与 AP 理论完全对齐，不做任何自作主张的设计
2. **架构清晰**：代码结构清晰，模块职责明确
3. **白箱可审**：所有决策过程可追踪、可解释
4. **完整实现**：实现 AP 理论的九大核心模块
5. **验收通过**：通过四类核心实验验证

### 1.2 核心理念

- **连续认知循环**：不是传统 LLM，而是持续运行的认知系统
- **闭环统计学习**：学习来自闭环统计，不是硬编码能力
- **双能量语义**：real_energy（外源证据）+ virtual_energy（内源预测）
- **快慢双系统**：快系统全池匹配，慢系统焦点发展
- **认知感受一等公民**：惊异、违和感、压力等作为系统核心信号
- **空 tick 延续**：无外部输入时系统仍能自主运行

## 八、重要注意事项

### 8.1 设计原则
1. **不要自作主张**：严格参考 PA 原型和理论文档，不自己发明设计
2. **保持拟人化**：所有设计要符合拟人化认知架构的理念
3. **白箱可审**：所有决策过程要可追踪、可解释
4. **渐进式升级**：每次只改一个模块，确保系统稳定

### 8.2 代码规范
1. **类型注解**：所有函数都要有类型注解
2. **文档字符串**：关键函数要有文档字符串
3. **测试先行**：每个模块都要有对应的测试
4. **白箱输出**：所有模块都要输出 trace 和 explainability

### 8.3 测试要求
1. **单元测试**：每个模块的核心功能
2. **集成测试**：模块间的协作
3. **验收测试**：四类核心实验
4. **回归测试**：确保不破坏现有功能

### 8.4 文档要求
1. **阶段报告**：每完成一个阶段写一份详细报告
2. **BUILD_STATUS**：及时更新构建状态文档
